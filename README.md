# Demo — Dự báo giá đối thủ (TP.HCM)

Mô phỏng trực tiếp trên bản đồ: chạy tập test qua model và hiển thị từng chuyến.

**Xem tại:** https://zilexz.github.io/demo-gia-doi-thu/

> ⚠️ Dữ liệu là **synthetic** — 1 nền tảng đối thủ, 2 dịch vụ, 3 khu vực, 11 ngày.
> Mọi con số mô tả hành vi bộ sinh dữ liệu, không phải thị trường TP.HCM thật.

Trang tự chứa: dữ liệu 216.090 chuyến nhúng sẵn trong `index.html`,
thư viện bản đồ Leaflet nằm trong `vendor/`.
